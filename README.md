# 🚀 Group 11 • Novara Cohort Memory Wall
### TS Academy Frontend Journey

A premium, interactive digital memory wall celebrating the journey of **Group 11** in the **Novara Cohort of TS Academy**. This project captures the evolution from "Bugs to Builds," featuring the cohort members, their learning roadmap, and the chaotic yet beautiful memories made along the way.

---

## ✨ Features

- **Interactive Hero**: High-impact introduction using GSAP animations.
- **Journey Timeline**: A curated roadmap of the Novara Cohort’s technical journey (HTML, CSS, JS, React).
- **Members Wall**: A responsive, animated grid featuring the 11 cohort members with personalized memories and graduation photos.
- **Behind the Scenes**: A mesmerizing, parallax-driven "Digital Scrapbook" of group chat screenshots using `data-speed` GSAP effects.
- **Hall of Fame**: A dedicated section for cohort awards, including the legendary "Group TroubleMaker" and "The Branch Detective."
- **Glassmorphic Navigation**: A high-end, responsive floating menu for seamless navigation across all devices.

## 🛠️ Tech Stack

- **Framework**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [GSAP](https://greensock.com/gsap/) (ScrollTrigger) & [Framer Motion](https://www.framer.com/motion/)
- **Typography**: Space Grotesk & Inter (Fluid Scaling)

## 📦 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

### CSS Build Process
This project uses a manual Tailwind build process to ensure maximum compatibility:
```bash
npx tailwindcss -i ./src/index.css -o ./src/tailwind-out.css --watch
```
